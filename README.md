# eventdesk-site

The public page served at https://eventdesk.me through GitHub Pages.

A static site with no build step: pushing to `main` publishes it.

- `index.html`: the page, with its CSS inline.
- `favicon.svg`, `apple-touch-icon.png`: the icon.
- `og-image.png`: the 1200×630 preview shown when the link is shared.
- `fonts/`: Fraunces, used for headings, self-hosted under the SIL Open Font License (`fonts/OFL.txt`). The page makes no third-party requests.
- `CNAME`: the custom domain. GitHub Pages depends on it.
