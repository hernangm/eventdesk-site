EventDesk

Answers about your event, from your own vetted information.

EventDesk is a conversational agent for event organizers. Attendees, speakers, sponsors and exhibitors ask it questions, and it answers using only what the organizer has loaded and approved, citing the source each time.

The problem

Close to an event, an organizer's office receives many messages a day. Most repeat questions that already have a published answer, the right answer changes as the event approaches, and the knowledge is spread across departments.

What EventDesk does

  • Answers from vetted sources onlyThe event website and the organizer's documents, each with a date, so every answer can point to where it came from.
  • Says when it does not knowIf no approved source holds the answer, it says so and points the person to the right department.
  • Shows staff what is missingEvery question it could not answer is recorded, so the team knows what to add next.
  • Uses no personal dataIn this first version every asker is anonymous and only public information is used.

Status

EventDesk is in development. The first version is being built with a professional congress organizer that runs medical, scientific and academic congresses.
